# Abada 1.1.0 publication gate report — 2026-10-14 (DRAFT)

## Decision

**NOT SIGNED OFF — draft evidence for the release owner.** This report records
what was run on a local host against the tree below. It is not a GO. Publication
is the release owner's decision and has not been requested: nothing was pushed,
tagged, merged to `main`, built as an image or published, and the version in
the repository is still `1.1.0-rc.2`.

`1.1.0` would close milestone M4 *Governed improvement and launch*. It adds
Flyway `V34` to `V38` (all additive) and additive endpoints (version history and
rollback, replays, authoring patch response). REST API v1 and worker protocol v1
stay backward compatible. See [`1.1.0-release-notes.md`](../release-notes/1.1.0-release-notes.md).

Unlike the `1.1.0-rc.2` gate, whose artifacts were built on GitHub Actions, this
evidence comes from a local host (macOS, Java 21, Node 24.18, Docker). A
publication needs the CI run and the tag workflow on the exact commit.

## Roadmap exit demo

The roadmap's demo — an override-rate finding, a proposal replayed on the last
20 cases and approved from the diff, one-click rollback, an engine replica
killed mid-replay — **was not run as one scripted demo on a real stack**. Its
steps are evidenced separately, and some only by simulation:

| Step | Evidence | Limit |
| --- | --- | --- |
| Override-rate finding names the agent and its review | analyzer unit tests with recorded facts; facts written by `PostgresInsightReviewFactTest` | The scheduled analyzer was not run end to end on a seeded corpus |
| Proposal as a small patch | golden authoring corpus (recorded model answers); `InsightLoopIntegrationTest` (LLM patch path) | No real model was called |
| Approval refused without a replay; plan with an estimate; run; read the diff; approve from it | `PostgresReplayTest` (policy gate incl. stale checksum, too few cases, rejection allowed, qualifying run adopts) | Model calls are a stub |
| Replay survives a replica dying mid-run | `PostgresReplayTest` (a lease that expired is claimed again and settled once) | A lease expiry is simulated; no process was killed |
| Nothing but the replay's tables is written | `PostgresReplayTest` (row counts of the runtime tables unchanged) | |
| One-click rollback | `PostgresRollbackTest` | |

The seeded corpus and the recorded video are not done (`scripts/dev` seed
script, the recording from `docs/assets/video/m4-demo-script.md`).
